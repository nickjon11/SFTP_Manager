# SFTP Manager v0.8.1.3 — Local Test

- File Permissions dialog for selected remote files or directories.
- Owner / Group / Others Read, Write, Execute checkboxes and live octal preview.
- Shows remote UID and GID.
- Confirms changes, applies with SFTP chmod using the current authenticated account.
- Records success or failure in Activity log.
- Does not attempt privilege escalation or recursive permission changes.
- Retains v0.8.1.2 features and local Windows BAT launcher.
- GitHub integration deferred to v0.8.2.
